We found this data as we were searching for public data on mortgages. 
It comes from the Home Mortgage Disclosure Act (HMDA) data published by the FFIEC, which requires lenders to report nearly every mortgage application. 
We downloaded 2025 New York applications for three large lending institutions. 
The dataset is interesting because it links many variables, including applicant demographics, finances, loan details, and neighborhood characteristics, to each lending decision and we have a broad scope on what we can analyze.
